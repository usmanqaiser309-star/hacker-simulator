# Hacker Simulator

Fake hacking screens for videos, pranks and movie-style props. Nothing here touches a real device or network; every screen is a visual simulation.

## Screens
- Hacker Typer: press any key (or tap) and code types itself, with terminal output beside it. Enter = run, Alt = Access Granted, Tab = Access Denied.
- CMatrix: falling matrix rain (green, red, blue, rainbow).
- Satellite: rotating globe, orbiting satellites, target lock, uplink log.
- Agent Data: fictional agent dossier with face scan.
- Phone Breach: fake phone unlock and data extraction sequence (the target name is editable).
- Hollywood: nine-panel wall of animated hacking displays.

Controls: speed slider, Auto typing, color theme, Fullscreen.

## Run
Open `index.html` in a browser. No build step. Fonts load from Google Fonts, so the first load needs internet.

## Deploy
Push to GitHub, then enable GitHub Pages (Settings > Pages > Deploy from branch > main / root).
